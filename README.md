# Prism

Gestionnaire de packs graphiques pour FiveM.

Ce dépôt sert uniquement à distribuer les mises à jour de Prism.

- **Installer Prism** : télécharger `Prism-Setup-x.y.z.exe` dans la dernière [Release](../../releases/latest).
- **Mettre à jour** : dans Prism, Paramètres → **Mises à jour**. Prism télécharge la nouvelle version, l'installe et redémarre.
